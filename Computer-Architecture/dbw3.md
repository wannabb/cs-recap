relational model

definition: realation + entity

constraints
  - domain
  - Key
  - Entity integrity
  - referential integrity

  1) **Domain constraints**
    - `atomic attribute` in domain value, allow `NULL` value
    > [!MEMO] 
    > atomic <=> composite attribute

  2) **Key constraints**
    - Super key and Candidate key
    > super key = set of unique attributes 
    > candidate key = set of unique and essential attributes
    - PK(primary key) = d ( d ⊆  candidate key)
  3) **Entity integrity constraints**
    - PK = unique & not `NULL`
